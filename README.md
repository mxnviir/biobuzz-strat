# BIOBUZZ build call

Should we put a nectar placer on the robot, or leave it off and shoot faster?

Single-file decision tool for the FTC 2026-27 game BIOBUZZ. Live at https://mxnviir.github.io/biobuzz-strat/ or open `index.html` locally; no build step. Enter your robot's numbers and the share of teams you expect to have a flower placer, and it averages the gain over every alliance you could be drawn into (partner with/without, opponents with 0/1/2 placers), picks the best match plan for each, and tells you whether building is a dominant strategy, a stable mix, or a tipping point.

Rule facts from Competition Manual TU01: Table 10-2 point values, G410 (nectar only in last 60 s), G418 (pollen drain), Figure 10-5 (bottom staged pollen does not score).
